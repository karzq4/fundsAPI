## Q: What the hell is this thing?


A: This is a lightweight C++ engine that helps me with commodity funds.


// 

## Q: Cool but how did you make it?

It was made in CMake and uses FetchContent (you know using API's and stuff).


//


## Q: So what does it even do?


A: It helps me with my commodity funds that i bought. It calculates a 50-day moving average and a 14-day RSI (Relative Strenght Index) to tell me if things will go bad (and i probably should sell my funds before i go broke and cry myself to sleep). It also puts the latest result in memory so it can compare it when a new result is calculated.
